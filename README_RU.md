# 🌻 Roblox Flowey Companion

Настольный компаньон, вдохновлённый Цветиком из *Undertale*, предназначенный для работы одновременно с Roblox. Программа отображает Цветика на экране и предоставляет интерактивный чат на основе Google Gemini AI.

## ✨ Возможности

* **Компаньон Цветик:** Отображает Цветика в небольшом окне на рабочем столе.
* **ИИ-чат:** Позволяет общаться с Цветиком с помощью Google Gemini API.
* **Эмоции и спрайты:** Поддерживает различные выражения лица Цветика.
* **Звуковые эффекты:** Поддерживает голосовые эффекты при наличии необходимых аудиофайлов.
* **Интеграция с Roblox:** Предназначен для работы одновременно с Roblox.
* **Перемещение окна:** Позволяет перемещать компаньона по рабочему столу.
* **Показ и скрытие:** Позволяет скрывать и показывать компаньона с помощью сочетаний клавиш.

## 🛠️ Требования

* Windows
* Python версии 3.10 или новее
* Roblox (необязательно, в зависимости от использования программы)
* API-ключ Google Gemini
* Необходимые изображения и аудиофайлы

## 📦 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/Mr-Suslik/roblox-flowey-companion.git
cd roblox-flowey-companion
```

### 2. Установка зависимостей

```bash
pip install psutil google-genai mss pillow keyboard
```

### 3. Настройка API-ключа

Создай переменную окружения `GEMINI_API_KEY` и укажи в ней свой API-ключ Google Gemini.

Если твоя версия программы поддерживает второй ключ, можно также настроить `GEMINI_API_KEY_2`.

**Важно:** Не публикуй API-ключи, пароли и другие секретные данные в репозитории. Не загружай на GitHub файлы, содержащие личные учётные данные.

### 4. Добавление необходимых ресурсов

Помести необходимые изображения Цветика в папку проекта или в подпапку `faces`.

Программа ожидает имена файлов в формате, похожем на следующий:

```text
Flowey 1 nice.png
Flowey 2 nice.png
```

Названия эмоций могут отличаться в зависимости от доступных спрайтов.

Файл стандартного голоса необходимо разместить рядом с `flowey.py`:

```text
flowey-normal-voice.wav
```

Дополнительные голосовые файлы для эмоций можно добавить, если они поддерживаются настройками программы.

### 5. Запуск программы

Запусти Python-скрипт:

```bash
python flowey.py
```

## 🎮 Управление

Стандартные клавиши, настроенные в программе:

| Клавиша / действие                 | Функция                                 |
| ---------------------------------- | --------------------------------------- |
| `F + Y`                            | Открыть или активировать интерфейс чата |
| `Z`                                | Скрыть компаньона                       |
| `X`                                | Показать компаньона                     |
| `Enter`                            | Отправить сообщение в чат               |
| Левая кнопка мыши + перетаскивание | Переместить окно                        |
| Правая кнопка мыши                 | Закрыть компаньона                      |

Управление может отличаться, если исходный код был изменён.

## 🔑 Безопасность API-ключей

Программа использует Google Gemini API.

* Храни API-ключи в секрете.
* Используй переменные окружения вместо хранения ключей непосредственно в исходном коде.
* Никогда не загружай API-ключи на GitHub.
* Если ключ стал публично доступен, отзови его и создай новый.
